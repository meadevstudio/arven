# Arven — Parfüm inceleme uygulaması

Arven; erkek, kadın ve unisex seçkilerini koku ailesi, notalar, kalıcılık, yayılım ve editör puanıyla keşfetmeye yarayan React + Vite uygulamasıdır.

## Çalıştırma

```bash
npm install
npm run dev
```

Uygulamadaki ürün görselleri, aynı 4:5 oranını koruyan yerel SVG data URI'lar olarak üretilir; harici görsel servisine ihtiyaç duymaz.
